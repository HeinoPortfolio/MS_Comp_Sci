#  Sample Project

- The purpose of this directoryis to hold the files that make up the backend of a simple socket.io server and a simple database. 
- The server can be run using the following command:
  - **npm start**

### File Directory

1) package.json
2) package-lock.json

- cors: ^2.8.5
- express: ^5.1.0"
- mongoose: ^8.20.0
- socket.io: ^4.8.1
